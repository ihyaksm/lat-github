# PRAKTIKUM GITHUB DAN VISUAL STUDIO CODE

## Tujuan Praktikum
1. Mengenal repository GitHub.
2. Memahami Fork dan Clone.
3. Menggunakan Visual Studio Code untuk mengedit berkas.
4. Memahami Commit dan Push.
5. Mengirim hasil pekerjaan melalui Pull Request.

## Petunjuk Praktikum

1. Buka repository GitHub yang dibagikan oleh guru.
2. Klik tombol Fork untuk menyalin repository ke akun GitHub masing-masing.
3. Buka Visual Studio Code.
4. Lakukan Clone terhadap repository hasil Fork.
5. Buat satu berkas HTML di dalam folder `tugas`.
6. Beri nama berkas menggunakan nama masing-masing.
7. Simpan perubahan.
8. Lakukan Commit dengan pesan:
   `Menambahkan tugas HTML - Nama Siswa`
9. Lakukan Push ke akun GitHub masing-masing.
10. Buka repository hasil Fork melalui browser.
11. Buat Pull Request ke repository utama milik guru.
12. Tunggu pemeriksaan dan persetujuan guru.

## Ketentuan Tugas

Buat satu halaman HTML sederhana yang berisi:
- Nama lengkap.
- Kelas.
- Judul halaman.
- Perkenalan singkat.
- Hobi atau minat.
- Cita-cita.

Simpan berkas di dalam folder `tugas`.

Contoh nama berkas:
`andi.html`

## Ketentuan Pengumpulan

- Setiap siswa hanya membuat satu berkas HTML.
- Tidak boleh menghapus atau mengubah berkas siswa lain.
- Setiap perubahan harus di-Commit dan di-Push.
- Pengumpulan dilakukan melalui Pull Request.
- Jangan mengirimkan password atau informasi pribadi ke repository.
